# SmartCart Retail SQL Analytics

## Project Overview

This project analyses a retail database using SQL and SQLite.

The aim of this project is to understand customer behaviour and evaluate whether promotional campaigns increase profitability. The analysis focuses on promotion performance, customer segments, product categories and sales channels.

This project was completed as part of the MSc Business Analytics programme at Warwick Business School.

## Business Questions

This project answers the following business questions.

- Which promotions generated the highest profit?
- Did promotional campaigns improve profitability?
- Which customer segments responded best to promotions?
- Which product categories generated the highest margin?
- How did different sales channels perform?
